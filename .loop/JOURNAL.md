# Журнал автономного цикла aae

Только дописывается в конец. Формат записи — в `CLAUDE.md`. Метки: ВОПРОС — нужен ответ владельца (до ответа
действует указанный вариант); НАХОДКА — факт, который стоит знать; РЕШЕНИЕ — принятое агентом решение по [Д]
или по пробелу в спеке; БЛОКЕР — дальше нельзя без владельца; НАРУШЕНИЕ — откат правок харнесса и т. п.;
ИТОГ — завершение цикла.
