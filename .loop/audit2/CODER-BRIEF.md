## Работа в общем дереве

В этом же рабочем дереве **одновременно** работают другие исполнители, у каждого своя зона файлов (в поручении).

- Меняй только файлы своей зоны. Нужна правка чужого файла — не делай, опиши в отчёте.
- `docs/init/AAE-SPEC.md` правит только исполнитель документации. Нужна правка спеки — напиши её текстом в отчёте.
- Файлы харнесса (`.claude/`, `scripts/loop/`, `CLAUDE.md`) и `.loop/OWNER-RULES.md` не трогай.
- Ошибка компиляции **в чужом файле** — сосед посреди правки: подожди 1–2 минуты и повтори, не чини. `cargo` может
  ждать блокировку `target/` — это нормально.
- Форматируй только свои файлы (`cargo fmt -p <свой крейт>` или `rustfmt --edition 2024 <файлы>`), не весь workspace.
- Коммить сам, атомарно, только свои пути: `git add <пути> && git commit -m ...` (не `git add -A`, не `git commit -a`).
  `index.lock` занят — повтори через пару секунд. Сообщение по-английски, без префикса WP; в конце:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Не пушь. История не переписывается.
- Каждому исправленному багу — тест, который краснеет без правки (проверь это: откати правку локально через
  `git stash`/обратный патч только своих файлов или убедись мутацией, затем верни).
- Перед сдачей: clippy своего крейта без предупреждений
  (`cargo clippy -p <crate> --all-targets -q --message-format short -- -D warnings 2>&1 | head -60`) и тесты затронутых
  крейтов (`cargo nextest run -p <crate> --no-fail-fast --status-level fail --final-status-level fail 2>&1 | tail -40`).
  Полный `mise run ci` не гоняй — его один раз запустит мастер после всех.
- Решения по [Д] и находки — записью в конец `.loop/JOURNAL.md` (формат в `CLAUDE.md`, роль `coder`, «цикл» — `аудит-2`).
