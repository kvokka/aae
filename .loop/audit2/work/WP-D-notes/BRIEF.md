## Цель

Решение владельца (спека §2.1 п. 18): то, что уже описано в `docs/`, из спеки убирается со ссылкой; сжатие не
ослабляет требований — сверка «оригинал → выжимка». Для каждой секции своей группы:

1. Выпиши требования оригинала секции. Оригинал — `/tmp/aae-spec-orig.md` (та же секция, найди через
   `grep -n '^##' /tmp/aae-spec-orig.md`), сравни с текущей `docs/init/AAE-SPEC.md` (текущая могла получить правки
   владельца по §2.1 — они важнее оригинала; решения §2.1 — в текущей спеке, раздел «2.1»).
2. Найди каждое требование в `docs/` (файл:строка). Проверь по коду (`grep`/`ast-grep` по `crates/`), если документ
   и спека расходятся, — документ должен описывать то, что есть в коде; расхождение кода со спекой — в отчёт, не чини.
3. Чего нет в `docs/` — допиши в целевой документ: по-английски, коротко, в стиле документа, в подходящий раздел.
   Метки [Р] (решение владельца) в документах не нужны; но каждое требование должно быть сказано.
   Маркеры `<!-- MEASURE id=... -->` из секции переносятся в документ рядом с числом, к которому относятся: id, date,
   ver, env, src — дословно, текст `note` — переведи на английский. Ни один маркер не должен потеряться.
4. Подготовь выжимку секции (по-русски, это внутренний документ) в формате уже сжатых секций, 3–8 строк:
   «Реализовано: …; код: `crates/...`; документация: `docs/...` (раздел)». Метки **[Р]**, стоявшие в секции,
   сохраняются в выжимке одной фразой («Ключ экземпляра — отпечаток **[Р]**»). Метки [Д] — можно одной фразой,
   если решение живо. Открытые [НП] (ещё не закрытые опытом) — назвать в выжимке. Закрытые [НП] — не упоминать, но
   только если закрытие записано в `docs/design/experiments.md` (дай ссылку в отчёте). Последняя строка выжимки:
   `Сжато: аудит-2, оригинал — git show ef08773:docs/init/AAE-SPEC.md`. Заголовок секции сохраняется.
   Образец (текущая §5.2):
   ```
   Реализовано: SQLite в WAL, статически слинкованная, единственный писатель — демон (CLI, плагины, агенты — только
   через API); в состоянии только рантайм, определения — в файлах конфига, прогон хранит снимок эффективного конфига;
   файлов-статусов, PID- и lock-файлов нет (один демон на каталог — flock на сам каталог состояния), живость — pid +
   время старта. Код: `crates/aae-core/src/store.rs`, `crates/aae/src/daemon.rs`. Описание — `docs/design/event-model.md`
   («State»).
   ```

5. Если секцию сжать нельзя (в `docs/` нет ≥ ~70 % и дописать без спора нельзя; требование противоречит коду; нужное
