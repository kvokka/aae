# WP-46 · `worktree = true` в формуле (subcoder)

## Что сделано

- Ключ формулы `worktree` (bool, по умолчанию false): `FormulaFile.worktree` (files.rs), `Formula.worktree`
  (config/mod.rs), перенос в items.rs. Неверный тип — ошибка serde с именем ключа.
- `[builtin.worktree]` убран как настройка: любая такая таблица (в оркестраторе или в `aae.toml` проекта) — ошибка
  конфига «`[builtin.worktree]` is gone: set `worktree = true` in the formulas whose runs need a worktree»
  (check.rs `bundled`). Списков `agents`/`formulas` и включения на уровне агента больше нет.
- Как флаг доходит до хука — минимальный путь без изменения машины прогонов и контрактов: загрузчик
  (`check::project_bundled`, получает `packs`) включает встроенный `worktree` для проекта, только если в его паках есть
  формула с `worktree = true`, и кладёт в его параметры `{"formulas": ["<pack>.<formula>", ...]}`. Плагин создаёт
  worktree на `run.preparing`, только если `run.formula` (квалифицированное имя, как в строке runs) в этом списке.
  Продолжение сессии (workdir уже worktree) и уборка на терминальных событиях — как раньше, по пути workdir.
- Почему не поле в `run.preparing`/RunView: это меняло бы контракт (contracts 1.3) и machine.rs (397 строк, у предела).
- Плагин `worktree.rs`: `Params { formulas }` (заполняет загрузчик), функция `chosen` удалена.

## Тесты

- aae-core `config_builtin`: без ключа — у проекта нет `worktree`; с ключом у `gascity.audit` — есть с
  `{"formulas":["gascity.audit"]}`; у оркестратора нет; `worktree = "yes"` — ошибка; старая таблица в оркестраторе и в
  проекте — ошибка с текстом замены. `config_layers` — пример замены таблицы проектом переведён на default-policy.
- aae-plugins `worktree_on_real_git`: выбор по формуле, а не агенту.
- aae-testkit `worktree.rs`: обе прежние проверки на формуле `build` с `worktree = true`; новая
  `a_formula_without_the_key_runs_in_the_rig` (workdir = рига, каталога worktrees нет).
- aae `tests/worktree.rs` (настоящий claude на фейковом API) — формула с ключом.
- Мутация: фильтр загрузчика `f.worktree || true` — падают `worktree_is_on_for_the_formulas_that_ask_for_it` и
  `a_formula_without_the_key_runs_in_the_rig`; откат — зелёные.
