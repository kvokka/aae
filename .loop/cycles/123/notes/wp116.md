Дата 2026-11-18, claude 2.1.326, codex-cli 0.169.0, linux-arm64 orbstack. Живых запусков — 0: оба фейка
вызывают компакцию сами (сообщают большой `usage.input_tokens`).

## Стенд (временный каталог, в репо не остаётся)

- `fake_anthropic.py` — Messages API в духе `aae-testkit/src/anthropic.rs`, но `usage.input_tokens` берётся из файла
  `tokens`, когда в тексте пользователя есть `BIG` или `CHILD` (иначе 10). Ответы: запрос компакции (в тексте
  пользователя `CRITICAL: Respond with TEXT ONLY`) → `<summary>FAKE SUMMARY</summary>`; `SPAWN <type>` → `Agent`;
  `BIG` → один `Bash true`; `CHILD` → четыре `Bash true`; иначе `OK`. Фейк testkit отдаёт фиксированные 10 токенов —
  компакцию им не вызвать, отсюда свой фейк.
- claude: `-p --input-format stream-json --output-format stream-json --verbose --setting-sources project,local
  --settings <f> --permission-mode bypassPermissions --model claude-haiku-5-5 [--agents …]`, env как в тестах адаптера
  (`ANTHROPIC_BASE_URL`, `ANTHROPIC_API_KEY=fake`, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`,
  `CLAUDE_CODE_MAX_RETRIES=0`), свой `CLAUDE_CONFIG_DIR` и `HOME`. Хуки в `--settings` пишут stdin в лог, ответ хука —
  из файла `out_<Event>` (опционально только при совпадении stdin), `exit_<Event>` — код выхода.
- `fake_openai.py` — Responses API (форма `aae-testkit/src/openai.rs`), те же правила; запрос компакции codex
  узнаётся по `CONTEXT CHECKPOINT` во входе; после `FAKE SUMMARY` в истории — только `OK` и 10 токенов (иначе codex
  компактит по кругу: история после компакции снова содержит `BIG`).
- `codex_rig.py` — клиент `codex app-server` по stdio (`-c analytics.enabled=false -c thread_unload_delay_secs=0`,
  env только PATH/HOME/CODEX_HOME/SHELL, свежие HOME/CODEX_HOME), несколько тредов в одном процессе;
  `@compact` → `thread/compact/start`.
- Окно claude-haiku-5-5 по `modelUsage.contextWindow` — 1 000 000.
