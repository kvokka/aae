## А. Баги и дыры (чинить без вопросов)

1. Демон живёт после смерти ядра: задача писателя из `run::start` не ждётся (`crates/aae/src/daemon.rs:132`, потом
   `drop((task, …))`). Ошибка SQLite или паника → API вечно отвечает 503, процесс не выходит, systemd не
   перезапускает. Нужно: задача ядра в `select!` с API, выход с ненулевым кодом.
2. Пороги сторожа инварианта 15 — `const` (`crates/aae-core/src/run/events.rs:17-20`, `machine.rs:18-19`,
   `gates.rs:13`): тишина 5/10/30 мин, `human_timeout`, start/queue/park. Спека и `contracts.md` требуют конфиг.
3. Инвариант 6 ослаблен: `exec.rs:178` ждёт только лидера группы; sweep потомков идёт в другом эффекте параллельно с
   запуском. Мутация «убрать ожидание» прошла все тесты, включая chaos; `invariants.md` ложно пишет, что chaos его
   проверяет (`check.rs:92` на деле проверяет «≤ 1 открытой попытки»).
4. Дренаж не останавливает повторные попытки: `start_attempt` не смотрит `stopping`; прогон в `interrupted` не в
   `active_runs` → новый процесс посреди планового рестарта.
5. Sweep в пути остановки (инв. 7, `exec.rs:105`) не покрыт testkit (мутация выжила). Resync не сверяет таблицу
   процессов с маркерами `AAE_INSTANCE` (инв. 20). Прогон в `finishing` при рестарте не переводится в `interrupted`.
6. `native.<harness>` сливается целиком, а не по ключу (`config/assemble.rs` `apply`): у оркестратора `{a=1,b=2}`,
   у рига `{b=3}` → итог `{b=3}`. Документ обещает «by key». Теста нет.
7. `explain` пишет слой `agent` у `system_prompt`, хотя в нём фрагменты плагинов.
8. `aae config check`/`explain` не работают без демона; `aae config reload` в CLI прячет массив `errors` (API его
   отдаёт).
9. Фронтенды: тот же `Idempotency-Key` с другим телом молча возвращает старый ответ (нужно 422); у MCP `start_run`/
   `cancel_run` ключа нет; ошибки при `--json` идут текстом; «нечего брать» в CLI — пустая строка с кодом 0
   (`cli/commands.rs:140`); `doctor` не показывает версию харнесса и голый путь при поиске через `PATH`; OpenAPI без
   схем ответов и без 400/404; неверный ключ ворот → 409 вместо 400; `gate close/open` печатают `null`.
10. Способности драйвера `reset_time` и `retries_429` нигде не читаются (мёртвые); `SessionStarted` не шлёт ни один
    настоящий адаптер. Либо использовать, либо удалить.
11. Окружение харнесса при наследовании хоста теряет `CLAUDE_CONFIG_DIR`, `HTTPS_PROXY`, `NODE_EXTRA_CA_CERTS`,
    `SSL_CERT_FILE` (`env_clear`). Для наследования хоста их надо пропускать.
12. codex: любая ошибка `thread/read` (в т. ч. таймаут) → `Transcript::Missing` → новая сессия. Контракт s02/s04 не
    закрепляет `retried_by_harness == false`.
13. Файлы состояния создаются по umask (0666 при umask 000); защищает только каталог 0700.
14. Флейки под нагрузкой: `crates/aae-testkit/tests/triggers.rs:204` (точное время без `start_paused`), `aae::api`
    (gate, trigger fire, restart), `aae::worktree` (`worktree.rs:92`). Пять демонов `acceptance-ci` умерли разом при
