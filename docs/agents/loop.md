# Developing loop-manager with devloop

The owner files an epic in the project's br tracker. The `epic` formula runs a coder, the repository test suite
and a reviewer. Each round takes its context from the epic's comments. Blocking questions wait for the owner.
The report step closes the epic and publishes the handoff.

See the [devloop guide](../../devloop/README.md) for installation, starting the daemon, filing an epic, answering
a question and recovering a run. The [agent definitions](../../devloop/agents/) give each role its instructions.
