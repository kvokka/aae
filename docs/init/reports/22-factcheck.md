## 4. Самые рискованные утверждения первой волны

Формулировка сильнее доказательства — в порядке убывания риска для итогового отчёта.

1. **«Nudge без tmux у Claude есть штатно: в inbox-сокет может писать внешний скрипт»** (17, строки 17 и 94). Дока
   гарантирует автодоставку только от собственных дочерних процессов сессии; для воркера в bypass-permissions сообщение
   извне по умолчанию удерживается и в `-p` через 5 минут отбрасывается. Формат сообщения в доке не описан, эксперимента
   нет. Подавать как гипотезу, требующую опыта с `crossSessionInbound: "accept"`.
2. **«Codex уже шарит stdio-MCP сам (`McpConnectionPool`)»** (18, п. 6) против **«MCP не шарится: два треда ⇒ два
   процесса»** (15). Оба верны условно: пул в `CODEX/codex-mcp/src/connection_pool.rs:1-5` шарит только соединения
   серверов на MCP 2026-07-28 («Legacy connections and servers that request input during startup remain private»), и это
   HEAD main. В бинарнике 0.166.0 строк `codex/connection-lease`, `codex/connection/open`, «failed to release a
   server-side MCP lease» нет (`strings … | grep -c` = 0), то есть как минимум lease-часть в 0.166 не входит. В итоговом
   отчёте нельзя писать ни «шарит», ни «не шарит» без условия.
3. **«Подписка работает и разрешена для личного использования»** (14, строка 19 и вывод на 158). Источники говорят
   «расходует лимиты подписки» и «не запрещает end user входить своей подпиской»; слова «разрешено» для автономного флота
   там нет, а Consumer Terms §3 про «automated or non-human means» в отчёте отсутствует. Плюс два непроверяемых довеска:
   «обещание предупредить заранее» (источник — блог Zed) и «политика менялась четыре раза за год» (17, без источника).
4. **«~80% проблем ACP-пути — недоработка Gas City, ~12% — протокол, 5% — адаптеры, 3% — харнессы»** (04). Это доли по

   будут прочитаны как измерение — заменить на «большинство».

7. **Лицензия br/bv: «задним числом» и отсутствие оценки риска** (12). Характеристика неверна, а реальный риск не
